    World difficulty
    
        
        
    Individual modifiers below apply after the preset, so they override it — set the preset first, then adjust anything specific. Combat, death penalty, and portals don't have official published multiplier numbers (Iron Gate never released exact values for these), so only labels are shown; resources and raids do, and those are shown.
    
        
        
        
        
        
    Raids uses an event rate rather than a multiplier — a higher number means a longer wait between raids, so "much less frequent" has the highest rate.
    
        
        
        
        
        
        
    These apply from the world's next start — no need for a connected admin to run console commands. An admin can also change them live in-game with setworldmodifier/setworldpreset/resetworldkeys, but that won't show up here since it happens outside this app.

    Advanced
    
        

        
    
          
          
        
    
      
    

      
    
        
    Restart warnings
    
        
    Sent to Discord only — vanilla Valheim has no way to broadcast a message into the game itself, so there's no in-game equivalent to offer here.
    
      
    

      
    
        
    Auto mod-update
    
        
        
        
        
    If the server is running when updates are applied, a restart is scheduled with the same 10/5/1-minute warnings as a manual scheduled restart.
    

        
    Crash detection
    
        
        
        
        
    Stops trying after too many crashes in a short window, so a genuinely broken mod can't trigger an endless restart loop — you'll get a Discord notification (if enabled) when it gives up.
    

        
    Daily restart
    
        
        
        
    Uses the same 20/10/5/1-minute warnings as a manual scheduled restart. Only fires if the server is already running at the time.
    

        
    Start on Windows login
    
        
    Adds a shortcut to your Startup folder so this manager launches automatically when you log in — the game server itself still needs Start clicked (or use auto-restart/daily-restart settings to keep it running).
    
        
    
        

        
    
          
        
    
      
    

      
    
        
    Discord notifications
    
        
    Manager-level events (server start/stop, restart warnings, mod updates). For in-game events — joins, leaves, deaths, shouts — install DiscordConnector from the Mods tab instead; it reports those directly and far more reliably than log-scraping can.
    
        
        
        
        
    
          
        
    
        
    
          
    Placeholders in {curly braces} get filled in automatically — leave them as-is unless you want to remove one.
    
          
          
          
          
          
          
        
    
        
    
          
        
    

        
    Players tab (optional)
    
        
    Add a free Steam Web API key to show Steam persona names for players who haven't spawned a character yet.
    
        

        
    Dashboard access
    
        
    This dashboard has no login by default. It only listens on this machine unless you turn on network access below — never forward this port on your router regardless of any setting here; see the README for why.
    
        
        
    Takes effect after fully restarting the manager (close the terminal/start.bat window and reopen it) — not just the game server.
    

        
    Login
    
        
    Strongly recommended if you've turned on network access above — otherwise anyone on your network can control the server with no password at all.

            Death history
            
        
            Vanilla Valheim's dedicated server doesn't log deaths at all, so this only catches deaths if an installed mod happens to print one to the console — it's best-effort, and currently nothing does that reliably. DiscordConnector (Mods tab) does track deaths properly, but stores them in a binary database format this app can't read — so instead of showing up here, they go straight to your Discord channel, which is the more reliable place to check them anyway.
